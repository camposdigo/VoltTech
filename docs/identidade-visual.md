# Identidade Visual — VoltTech

## Conceito visual

A identidade da VoltTech foi pensada para transmitir tecnologia, energia e uma percepção premium. O protótipo utiliza uma base escura com pontos de destaque em vermelho, criando contraste forte e associação com velocidade, potência e universo gamer/tech.

## Paleta de cores

Paleta sugerida com base no protótipo:

| Uso | Cor | Hex |
| --- | --- | --- |
| Fundo principal | Preto profundo | `#0A0A0A` |
| Superfícies/cards | Grafite | `#171717` |
| Cor de destaque | Vermelho VoltTech | `#E50914` |
| Destaque escuro | Vinho tecnológico | `#7A1018` |
| Texto principal | Branco | `#FFFFFF` |
| Texto secundário | Cinza claro | `#B8B8B8` |

Os valores podem ser refinados posteriormente a partir dos estilos definitivos do arquivo Figma.

## Tipografia

Para manter uma interface moderna e legível, a aplicação utiliza como referência uma tipografia sans-serif de aparência limpa.

Sugestões compatíveis com o conceito:

- Inter
- Poppins
- Roboto

Para o MVP Flutter, a prioridade é manter boa legibilidade e hierarquia visual, mesmo que a fonte definitiva ainda seja ajustada.

## Logo

O logo da VoltTech deve ser simples, reconhecível em tamanhos pequenos e funcionar tanto em fundo escuro quanto claro. A construção visual pode explorar elementos relacionados a:

- raio;
- energia;
- eletricidade;
- letra V;
- movimento e velocidade.

## Diretrizes de interface

- Fundos predominantemente escuros.
- Vermelho reservado para ações, preços promocionais e elementos de destaque.
- Cards com contraste discreto em relação ao fundo.
- Pouco texto por bloco.
- Imagens de produto com bastante espaço visual.
- Botões com boa área de toque e contraste.
- Hierarquia clara entre preço, nome do produto, avaliação e CTA.

## Sensação desejada

Ao abrir o aplicativo, o usuário deve perceber uma marca tecnológica, atual, rápida e confiável, sem excesso de elementos visuais.
